# @millstrand/spool-batteries

Everyday graph operations: add/show/list/ready/update, batches, queries, edges, notes, archival, supersede and burn. Requires the `@millstrand/core` peer package; no prerequisite spools.

Select `"@millstrand/spool-batteries"` in workspace `spools`, or default-export `batteries(namedQueries)` from a local module. The package's default export is an inert, unconfigured Batteries spool. Shared query helpers such as `equals` belong to core, not Batteries.
